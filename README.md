**GDMenu Music Changer**

A Geode mod for Geometry Dash that lets you change the main menu music.

Features

* Choose between Neon Runner, Cube Drift, and Spike Pulse.
* Randomly select one of the bundled tracks.
* Play your own music using MP3, OGG, or WAV files.
* Turn off custom music to use the default Geometry Dash menu music.
* Use the Next song button on the main menu to switch tracks.

Installation

1. Install Geode. [geode-skh](https://geode-sdk.org/install)
2. Download the latest .geode file from the Releases  page. [v1.4.0](https://github.com/angie689/GDMenu-Music-Changer/releases/tag/1.4.0)
3. Open the file to install the mod.
4. Launch Geometry Dash and configure the mod in its settings.

Custom Music

1. Open the mod’s settings.
2. Set Menu song to Custom file.
3. Select an audio file under Custom song file.

Supported formats: MP3, OGG, and WAV.

Compatibility

The mod targets Geode 5.11.1 and lists support for Windows, macOS, and iOS.
